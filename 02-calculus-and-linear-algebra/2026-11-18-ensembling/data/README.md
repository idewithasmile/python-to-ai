# Session Data: Ensembling Fixtures and Benchmark Data

This directory contains the submission CSV prediction fixtures and synthetic benchmark classification dataset used by the study guide and notebooks in [Ensembling](../README.md).

## Files and Schemas

### 1. `method1.csv`, `method2.csv`, `method3.csv`

- **Format:** Comma-separated values (CSV) with header.
- **Description:** Sample prediction files generated by three candidate baseline models for an image digit classification task.
- **Schema:**
  - `ImageId` (`int64`): Unique image identifier (`1` to `5`).
  - `Label` (`int64`): Predicted class label (`0` through `9`).
- **Target usage:**
  - Demonstrating majority voting consensus (`Voting.ipynb` / `01_voting_ensembles_and_diversity.ipynb`).
  - Calculating pairwise prediction correlations (Pearson, Spearman rank, Kendall's tau) in `correlations.ipynb`.
  - Computing arithmetic average predictions across files in `Averaging.ipynb`.
  - Converting predictions to ordinal ranks and computing percentile rank averages in `Rank_Averaging.ipynb`.

### 2. `_w2_method2.csv`, `_w2_method3.csv`, `_w3_method1.csv`

- **Format:** Comma-separated values (CSV) with header.
- **Description:** Weighted model submission variants containing multiplier hints encoded directly in the file naming convention (`_w2_` represents weight multiplier 2, `_w3_` represents weight multiplier 3).
- **Schema:**
  - `ImageId` (`int64`): Unique image identifier (`1` to `5`).
  - `Label` (`int64`): Predicted class label.
- **Target usage:**
  - Demonstrating automated regular-expression weight extraction: `pattern = re.compile(r".*_[wW](\d+)_.*")`.
  - Evaluating weighted majority voting where higher-capacity models cast multiple votes in the aggregation tally.

### 3. `synthetic_classification.csv`

- **Format:** Comma-separated values (CSV), 500 rows × 21 columns.
- **Description:** Reproducible, self-contained binary classification dataset generated via `sklearn.datasets.make_classification` (`random_state=42`). Used for cross-validation ensembling and holdout blending pipelines without external network dependencies.
- **Schema:**
  - `feature_00` to `feature_19` (`float64`): 20 continuous numerical features (12 informative features, 4 redundant linear combinations, 4 random noise features).
  - `target` (`int64`): Binary classification ground truth label (`0` or `1`), with an approximate 60:40 class distribution.
- **Target usage:**
  - 5-fold cross-validation probability averaging with heterogeneous estimators (SVC, Random Forest, KNeighborsClassifier) in `02_probability_averaging_and_cv.ipynb`.
  - Analyzing probability calibration disparities (Platt-scaled SVM margins vs. tree ensembles) and rank-based ROC-AUC corrections in `03_rank_averaging_and_calibration.ipynb`.
  - Partitioning into train-blend (70%), holdout (30%), and test sets for Level-1 meta-model training in `04_linear_and_meta_blending.ipynb`.
