# Session Data: Recursion Sequences, String Inversion Benchmarks, and Subarray Tests

This directory contains lightweight, portable datasets and test assets used by the notebooks and study guide in [Recursion and Two Pointer](../README.md). Every file is self-contained so that all examples, algorithms, and exercises run locally without external dependencies.

## Files and Schemas

### `subarray_sum_cases.json`

A structured JSON document containing test cases for the Subarray Sum problem (LeetCode 560 non-negative variant). Used to validate both the $O(n^2)$ nested-loop brute force implementation and the $O(n)$ two-pointer sliding window approach.

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `id` | `string` | Unique benchmark case identifier | `"case_01_lecture_example"` |
| `array` | `list[integer]` | Input integer array ($a_i \ge 0$) | `[1, 2, 3, 5, 6]` |
| `key` | `integer` | Target sum value $k$ | `5` |
| `expected_count` | `integer` | Total number of contiguous subarrays summing to `key` | `2` |
| `subarrays` | `list[list[integer]]` | Explicit list of contiguous subarrays achieving the sum | `[[2, 3], [5]]` |
| `description` | `string` | Clarification of the test case condition | `"Standard lecture example with non-negative numbers"` |

- **Format:** JSON array of objects (UTF-8 encoding)
- **Target usage:** Verifying correctness of pointer expansion (`i`) and pointer contraction (`j`), ensuring matching subarrays are detected without undercounting or double-counting.

### `two_sum_sorted.csv`

A tabular dataset of sorted integer arrays paired with target values, used for testing the convergent two-pointer technique on sorted sequences (LeetCode 167).

| Column | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `case_id` | `string` | Benchmark case identifier | `"ts_01"` |
| `array` | `string` | Comma-separated sorted integer sequence | `"2,7,11,15"` |
| `target` | `integer` | Target sum sought | `9` |
| `index1` | `integer` | 0-based index of the first term in the solution pair | `0` |
| `index2` | `integer` | 0-based index of the second term in the solution pair | `1` |
| `val1` | `integer` | Value at `index1` | `2` |
| `val2` | `integer` | Value at `index2` | `7` |

- **Format:** Comma-separated values (UTF-8 encoding)
- **Target usage:** Benchmarking $O(n)$ two-pointer search on sorted arrays against $O(n^2)$ exhaustive pair checking.

### `palindromes_and_strings.json`

A collection of test strings covering ASCII words, mixed-case strings, punctuation-heavy phrases, and palindromes. Used for testing in-place string reversal algorithms and convergent pointer palindrome verification.

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `id` | `string` | Unique case identifier | `"str_04"` |
| `input` | `string` | Original input string | `"A man, a plan, a canal: Panama"` |
| `reversed` | `string` | Exactly reversed character sequence | `"amanaP :lanac a ,nalp a ,nam A"` |
| `is_palindrome` | `boolean` | Strict character-by-character palindrome match | `false` |
| `alphanumeric_palindrome` | `boolean` | Palindrome status ignoring case and punctuation | `true` |

- **Format:** JSON array of objects (UTF-8 encoding)
- **Target usage:** Testing two-pointer string reversal (LeetCode 344) and two-pointer alphanumeric palindrome validation (LeetCode 125).

---

### `fibonacci_words.json`

A structured JSON dataset specifying the Fibonacci Word sequence generated by the recurrence $F(0) = \text{"A"}, F(1) = \text{"B"}, F(n) = F(n-1) + F(n-2)$, directly corresponding to the exercise in the lecture slides (Slide 64).

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `target` | `integer` | 1-based index target requested | `4` |
| `closest_n` | `integer` | Smallest recurrence step $n$ where $|F(n)| \ge \text{target}$ | `4` |
| `word_length` | `integer` | Total character length of string $F(n)$ | `5` |
| `word_sample` | `string` | Full generated string sequence for verification | `"BABBA"` |
| `expected_char` | `string` | Character at position $\text{target} - 1$ in $F(n)$ | `"B"` |
| `note` | `string` | Analytical explanation and derivation note | `"Slide 64 benchmark: target=4 -> n=4, F(4)=BABBA, len=5 >= 4, F(4)[3]=B"` |

- **Format:** JSON array of objects (UTF-8 encoding)
- **Target usage:** Validating recursive string concatenation and demonstrating how to find the character at index $\text{target}-1$ recursively without storing astronomical strings in memory.
